Current implementation and requested result
The app has one screen with a fixed 700 × 650 canvas and Scale to fit on.
The heading, field labels, and a save message use several names for the same
counts. The heading, field labels, and recovery date input use Verdana.

Use “iQuery and Mavericks Log” for the heading and app display name, and
“iQueries Completed” and “Mavericks Completed” for the two count labels. Let
the existing background fill the Power Apps viewport. Keep the form centered
and cap its width at 700. Use Open Sans wherever Verdana is currently set.

Impact and dependencies
The iQueries card display name feeds its label and input tooltip. The save
message edit changes only the text shown when recovery details are missing.
Keep the existing SharePoint bindings, including 'Daily PNQ Log',
PNQsCompleted, and WilbursCompleted. The iQueries and Mavericks labels apply
inside this app. The linked SharePoint view and Power BI report use their own
labels.
On wide windows, the heading and icons share one row. At widths below 660,
the title sits under the icons so they stay separate. On short windows, the
screen can scroll down to the end of the form. The app fills the available
Power Apps viewport, which may be bounded by the host if the app is embedded.

Apply in the development app
Follow the blocks in order. Paste formulas without an initial equals sign.
For a property on a locked data card, select the card in Tree view and use
Advanced > Unlock to change properties. Keep the card and the existing input.
Use the formula bar for layout changes so Studio does not rewrite the
formulas as fixed coordinates when you drag controls.
